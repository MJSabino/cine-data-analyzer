#  CineData & AI Insights

Script em **Python** focado em extração de dados de entretenimento e processamento analítico com Inteligência Artificial (API Groq) para geração de relatórios de curadoria e recomendações automatizadas.

##  Tecnologias
* Python
* API Groq (LLM)
* Automação e Manipulação de Dados
